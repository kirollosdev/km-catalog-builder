KM Catalog Builder icons

Drop image files in this folder and they appear in Elementor's icon picker,
under the "KM Catalog Builder" tab. Nothing else to do: no code, no rebuild.

SVG, WebP, PNG and JPG are read. The file name becomes the icon's name in the
picker, so "free-delivery.svg" shows as "Free Delivery".

An SVG is printed into the page, so it takes the colour around it. The others
are shown as images at whatever size the widget asks for, which means a PNG or
a WebP wants to be about twice the size it will be seen at.
